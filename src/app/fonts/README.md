# Local typefaces

These are the unchanged Latin variable-font files previously loaded by `next/font/google`. Bundling them through `next/font/local` keeps the same typography without requiring Google Fonts during a build or a visitor request.

- Inter: weights 100–900; [upstream](https://github.com/rsms/inter), license in `Inter-OFL.txt`.
- Sora: weights 100–800; [upstream](https://github.com/sora-xor/sora-font), license in `Sora-OFL.txt`.
- JetBrains Mono: weights 100–800; [upstream](https://github.com/JetBrains/JetBrainsMono), license in `JetBrainsMono-OFL.txt`.

License copies are from the Google Fonts repository's `ofl/inter`, `ofl/sora`, and `ofl/jetbrainsmono` directories. Keep these licenses alongside the font files.
